NWA is built entirely on open-source and open-standard technologies certified by international meteorological bodies.
RUNTIME Node.js 24 (LTS)
Event-driven, non-blocking JavaScript runtime for high-throughput async I/O. Built-in node:sqlite module.
nodejs.org
DATABASE SQLite 3 (WAL Mode)
ACID-compliant embedded relational database with Write-Ahead Logging for concurrent reads and atomic write transactions.
sqlite.org
WEATHER API Open-Meteo
Free, open-source, WMO-standard weather API. 16-day forecasts, hourly models, historical archive. No API key required.
open-meteo.com
MAPS Leaflet.js 1.9
Open-source interactive mapping library. Tile layers from OpenStreetMap (ODbL). Used for real-time geolocation and station markers.
leafletjs.com
DISASTER API UN GDACS
Global Disaster Alert and Coordination System by the United Nations and European Commission. Real-time cyclone, flood, and storm RSS feeds.
gdacs.org
CHARTS Chart.js 4
MIT-licensed responsive chart library used for category distribution, trend analysis, and state-wise event frequency plots.
chartjs.org
EXPORT SheetJS (xlsx) + jsPDF
Open-source spreadsheet (SheetJS) and PDF generation (jsPDF) for downloadable official meteorological reports.
sheetjs.com
AI/NLP TF-IDF + Naive Bayes
Custom NLP credibility engine built in pure Node.js. TF-IDF vectorization + Multinomial Naive Bayes classifier for report authenticity scoring.
ai_classifier.js (custom built)
STANDARD WMO BUFR/SYNOP
World Meteorological Organization code standards. Open-Meteo weather codes mapped to WMO BUFR present weather descriptions.
wmo.int
